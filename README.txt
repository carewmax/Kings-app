HOW TO GET THE APK (free, ~5 minutes, no Play Store needed)

1. Go to github.com and sign in (free account is fine).
2. Click "+" (top right) -> New repository. Name it kings-app. Click Create.
3. Click "uploading an existing file". Drag in EVERYTHING from this folder
   (the www folder, icon folder, .github folder, package.json, capacitor.config.json).
   Make sure the ".github" folder goes up too. Click Commit changes.
4. Click the "Actions" tab. The "Build APK" job runs by itself (about 4-6 min).
   If it asks, click "I understand my workflows, enable them".
5. When it has a green tick, click it, scroll to "Artifacts",
   download "Kings-Electricals-APK". Unzip -> app-debug.apk.
6. Send app-debug.apk to your phone (WhatsApp/Drive/cable), tap it,
   allow "Install unknown apps". Done - it opens as a real app, no Chrome.
